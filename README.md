# C# Practice

This repository contains my C# programming practice, exercises, and small programs.
The purpose is to learn C# step by step through practical examples and challenges.
## Requirements

* .NET SDK
* Visual Studio Code
* C# Extension

## Create Project

```bash
dotnet new console -n ProjectName
cd ProjectName
code .
```

## Create Class

### PowerShell or Terminal

```powershell# 
New-Item ClassName.cs
```

### Git Bash

```bash
touch ClassName.cs
```

## Run

```bash
dotnet run
```

## Build

```bash
dotnet build
```

## Git

```bash
git add .
git commit -m "Add C# practice example"
git push
```
